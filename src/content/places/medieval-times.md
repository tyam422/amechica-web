## 概要

Medieval Times（Dinner & Tournament）は、11世紀のスペインを舞台にした、食事をしながら見るショーの会場です。6人の騎士が馬上の槍試合（ジョスト）や剣の試合をし、馬やタカ（鷹）の演技もあります。ショーの間に 4 品のコースの食事が出ます（公式サイト）。

公式サイトによると、Chicago の会場（Schaumburg）は Medieval Times の中で大きい会場のひとつで、1,400 人以上が座れます。ほかにアメリカ・カナダに会場があります（Atlanta、Baltimore、Buena Park、Dallas、Lyndhurst、Myrtle Beach、Orlando、Scottsdale、Toronto）。

## ショーの内容

公式サイトによります。

| 項目 | 内容 |
| --- | --- |
| ショー | 6人の騎士の馬上の槍試合（ジョスト）、剣の試合、素手の戦い、乗馬の演技、タカ（falcon）の飛行。勝った騎士が「Defender of the Throne」になります |
| 応援 | 受付でかんむり（crown）をもらいます。かんむりの色で応援する騎士が決まります。席に入るときも色で呼ばれます |
| 馬 | アンダルシア（Pure Spanish）の馬。屋外の囲い（paddock）で見られます |
| Hall of Arms | 入口のホール。よろい・武器などの展示、おみやげの店、剣の店（Sword Shop）、バー |
| 写真 | 入るときに写真を撮ります。カメラ・ビデオは持ち込めます（フラッシュは使えません） |
| Knighting Ceremony | ショーの前に、騎士にしてもらう儀式（有料、チケットを買うときに追加） |
| 照明 | ストロボ（点滅する光）を使います |

## 食事（Four-Course Feast）

公式サイトの The Feast のページ・FAQ によります。食事はショーの間に出ます。フォークなどの食器は頼むと出してもらえます。残ったものは持ち帰れます。

| 種類 | メニュー |
| --- | --- |
| ふつうの食事 | ガーリックブレッド、トマトのスープ（tomato bisque）、ローストチキン、バターのとうもろこし、ハーブのポテト、デザート、コーヒー、ソフトドリンク 2 杯 |
| ヴィーガン | フムス・にんじん・セロリ、3種の豆の煮込みと玄米、フルーツまたはイタリアンアイス |
| ベジタリアン | ヴィーガンの料理とピタパン（The Feast のページではデザートはチョコレートエクレア） |
| グルテンフリー | トマトのスープ、フムス・にんじん・セロリ、ローストチキン、とうもろこし、ポテト、フルーツまたはイタリアンアイス |

- ヴィーガン・ベジタリアン・グルテンフリーの食事は、席についたときに係の人（server）に伝えます。
- 公式サイトの「Accommodation Meals」の表（2025年4月の日付）には、ほかに乳製品なし、大豆なし、コーシャ（Kosher）、玉ねぎなし、にんにくなし、卵なし、ナッツなしの食事が載っています。グルテンフリーは「セリアック病の人も食べられる」と書かれています。
- 材料表によると、料理にピーナッツ・木の実（ナッツ）は使っていませんが、ナッツを使わない工場で作っているとは限りません。ハラール（Halal）のチキンは会場によって違います（店の人に確認）。
- 昼の公演（Matinee）用の材料表・食事の表は、夜の表と別です（例：デザートがチョコチップクッキー）。
- 材料の都合で、料理が変わることがあります。
- お酒はバーで買えます（21歳以上、写真つきの身分証明書が必要）。
- 外からの食べ物・飲み物・ケーキは持ち込めません。ケーキ 1 切れを予約に追加できます。

## 予約・グループ

- 公式の FAQ によると、席の数が限られているので予約（チケットを先に買うこと）が強く勧められています。オンラインまたは 1-888-WE-JOUST で買えます。
- 一緒に座りたい場合は、1 つの予約にまとめます。別の予約の人と座る場合は、当日の窓口で全員の注文番号を見せます（同じパッケージ・空きがある場合だけ）。
- アメリカ・カナダ以外からはオンラインで買えません（電話で買えます）。
- 日を決めないギフトのチケットもあります。

公式サイトの誕生日のページによります。15人以上はフォームから会場のイベントの担当者に連絡します。15人未満はふつうのチケットで予約します。

| Dinner & Tournament | ショー、4 品の食事、ショーの中でグループの名前の紹介、グループで座れる |
| Joust | 上の内容に加えて全員の写真、応援の旗 |
| Party Package | Joust の内容に加えてケーキ 1 切れ、スラッシー（おみやげのカップ） |
| Knight's Banquet | Joust の内容に加えて良い席、VIP のランヤード、飲み物 1 杯 |
| Noble Fare | Knight's Banquet の内容（飲み物 2 杯）に加えて 1 人の Knighting Ceremony |
| Crown Jewel | Noble Fare の内容に加えて VIP のグループ席、おみやげのグラス、席に水 1 本 |

## 年末年始・休日の公演

- 公式サイトでは、Chicago の会場のホリデー向けの特別なショーは見つかりませんでした（2026年11月14日）。
- カレンダーでは、Thanksgiving（11月26日）と Christmas（12月25日）は公演がありません。Christmas Eve（12月24日）は 16:00 の 1 回です。
- 12月26日〜2027年1月2日は、ほとんどの日に 1 日 3 回（13:15、16:00、18:45）の公演があります。New Year's Eve（12月31日）と New Year's Day（1月1日）も 3 回です。
- FAQ によると、ホリデーのパーティーのグループの予約もできます。

### 車

公式サイトによると、I-90 の近くで、Chicago のダウンタウンから車で行けます。Schaumburg の N Roselle Rd 沿いです。駐車場は無料です。
