## 概要

Walmart Supercenter は、食品、日用品、服、家電、おもちゃ、薬などを売る大型のディスカウントストアのチェーンです。この店の名前は「Streamwood Supercenter」（店舗番号 1420）で、Streamwood の S Barrington Rd 沿いにあります。

店の中に、薬局、Vision Center（めがね）、Subway、ガソリンスタンド（Walmart Fuel Station）、EV の充電スタンドなどがあります（公式サイトの店舗データ）。

## 返品

会社のサイトの Return Policy（2026年11月2日更新）と、walmart.com の返品のページによります。

| 買ったもの | 返品できる期間 |
| --- | --- |
| ほとんどの商品 | 90日 |
| 家電（Consumer Electronics）、冷暖房、掃除機、パソコン、電動自転車など | 30日 |
| ほとんどの携帯電話 | 14日 |
| 大型の家電（冷蔵庫・洗濯機など） | 配達から 2日（未開封なら 30日）。店では返品できません |
| コンタクトレンズ、補聴器、度つきのめがね | 60日 |
| 芝刈り機などの庭の道具、タイヤ、写真・名入れの商品 | 90日 |
| 多年草・低木・木 | 365日（店だけ） |

- 2026年10月1日〜12月31日に買ったほとんどの商品は、2027年1月31日まで返品できます（携帯電話、保証プラン、大型の家電、Dyson の製品などは除く）。
- 生鮮食品（野菜・果物、花、肉、ベーカリー、デリ、乳製品、冷凍食品）は、レシートがあれば返金されます（Fresh Guarantee）。
- レシートがない場合は、政府発行の写真つきの身分証明書が必要です。認められると Walmart のギフトカードで返金されます。
- 返品できないもの：処方薬、糖尿病の測定器・試験紙、銃・弾薬、ギフトカード、宝くじ、プリペイドの携帯電話の分数など。
