## 概要

Target は、服、日用品、食品、家電、おもちゃ、家の物などを売る大型のディスカウントストアのチェーンです。この店の名前は「West Schaumburg」（店舗番号 835）で、Schaumburg Rd と Barrington Rd の近くにあります。Target の店舗データでは、店の形は「SuperTarget」（食品の売り場が広い店）で、1 階建てです。

店の中には、Starbucks、CVS pharmacy（薬局）、Target Optical（めがね）があります。

## 返品

公式サイトの返品のページ（2026年11月14日に確認）によります。

| 買ったもの | 返品できる期間 |
| --- | --- |
| ほとんどの商品（未開封・新品の状態） | 90日 |
| Target のオリジナルブランド（Owned Brand） | レシートがあれば 1年 |
| 家電・エンターテインメント（Apple・Beats を除く） | 30日 |
| Apple・Beats の製品、携帯電話 | 14日 |
| 化粧品 | 開けていても 90日（Target Circle Card で買った場合は 120日） |
| Target Circle Card・Target Circle 360 | ほとんどの商品で 30日長くなります |
| 返品できないもの | トレーディングカード、ギフトカード |

- 2026年11月1日〜12月24日に買った家電・エンターテインメントなどは、返品の期間が 12月26日から始まります（家電・エンターテインメントは 2027年1月24日まで、Apple・Beats・携帯電話は 2027年1月8日まで）。
- Starbucks、CVS pharmacy、Target Optical で買ったものは、それぞれの売り場で返品します。
- 返金は、ふつう払ったときの方法に戻ります。
