飛行機の国内線の保安検査や、一部の連邦施設に入るとき、州の運転免許証や身分証明書は、REAL ID（リアルID）の基準を満たすものか、パスポートなど別の認められる身分証明が必要です。これは連邦の基準で、カードそのものは各州が発行します。イリノイ州では、州務長官（Secretary of State）の Driver Services（いわゆる DMV）で申請します。運転そのものの試験や、日本の免許からの切替は「[イリノイ州の運転免許証](/topics/illinois-drivers-license/)」を見てください。社会保障番号は「[社会保障番号（SSN）](/topics/social-security-number/)」を見てください。

## REAL ID とは、いつから必要か

REAL ID は、2005年の連邦法（REAL ID Act）に基づく、州が発行する運転免許証・身分証明書の保安基準です。国土安全保障省（DHS）と運輸保安庁（TSA）の案内では、この基準を満たすカードには、通常、金色の星などの印があります。

TSA と DHS によると、<strong>施行は 2025年5月7日</strong>に始まりました。この日から、連邦の検査場や多くの連邦施設では、州が発行した免許やIDは、REAL ID に適合したもの（星の印があるもの）か、後述の別の認められる書類だけが使えます。星のない州の免許だけを持っていっても、空港の身分証明としては認められません（TSA）。

一方、REAL ID がなくても、<strong>運転は標準の運転免許証でできます</strong>（イリノイ州務省、DHS）。投票、連邦の給付の申請、身分証明がもともと不要な連邦施設の一般区域、警察署への連絡などにも、REAL ID は必要ない、と連邦保護局（Federal Protective Service）は案内しています。施設ごとに入り口の条件が違うことがあるので、行く前にその施設の案内を見てください。

## 何に必要で、何の代わりになるか

主に次の場面で、REAL ID か、それに代わる認められる身分証明が求められます（TSA、DHS）。

- 米国の民間機への搭乗（国内線の空港保安検査。18歳以上）
- 多くの連邦施設への入場
- 原子力発電所への入場

<strong>外国政府が発行したパスポート</strong>は、TSA の認める身分証明の一つです。日本のパスポートは、ここに含まれます。米国のパスポートやパスポートカード、永住者カード（グリーンカード）、DHS の Trusted Traveler（Global Entry、NEXUS など）、雇用許可証（I-766）、軍のIDなども、公式の一覧にあります。一覧は変わることがあるので、出発前に TSA の公式ページで確認してください。

国内線では、REAL ID とパスポートの<strong>両方</strong>は不要で、認められるものが1点あれば足ります（TSA）。一方、国外へ出るときは、これまでどおりパスポートが必要です。REAL ID の免許があっても、旅券の代わりにはなりません。

18歳未満の子どもは、米国内の移動では、TSA は身分証明を求めない、と案内しています（一人で TSA PreCheck を使う場合などを除く）。航空会社側のルールは、各社に確認してください。

認められる身分証明がまったくないときは、2026年2月1日から、TSA ConfirmID という本人確認を、手数料 <strong>45ドル</strong> で使える選択肢がある、と TSA は案内しています（有効は旅行開始日から10暦日、とされています）。紙の仮免許（temporary driver's license）は、TSA の認める身分証明ではありません。まず、パスポートか星のある本カードを持っていくのが確実です。

## イリノイ州での見分け方

イリノイ州の REAL ID には、免許でも州IDでも、カードの<strong>右上に小さな金色の星</strong>があります。星があれば REAL ID です（州務省）。星がなく、「Federal Limits Apply」などと書かれた標準のカードは、運転や州内の身分証明には使えても、空港の検査では州の免許としては使えません。

米国市民でも永住者でもなく、難民や承認された亡命でもない人が取る REAL ID の免許には、<strong>Limited Term</strong>（期限付き）と表示する、と州法にあります（625 ILCS 5/6-115）。一時的な就労ビザなどで取るカードが、これに当たります。

連邦の規則では、一人が持てる REAL ID は1枚です。星のある運転免許証と、星のある州IDの両方は持てません（イリノイ州務省）。運転しない人は、星のある州IDを申請できます。運転する人は、星のある運転免許証を申請します。切替や試験の手順は「[イリノイ州の運転免許証](/topics/illinois-drivers-license/)」を見てください。

## 一時滞在のビザで取るとき

米国市民でなくても、合法的な滞在資格（lawful status）があり、SSN を持っていれば、イリノイ州の REAL ID を申請できる、と州務省は案内しています。対象の例として、永住者、一時的な保護の資格、有効な学生ビザや就労ビザの所持者（SSN がある場合）が挙げられています。L-1、E、H-1B などの就労ビザ本人は、通常この案内に含まれます。家族ビザ（L-2、H-4、E の家族など）も、合法的な滞在と SSN があれば、同じ案内の範囲に入り得ます。SSN をまだ取れない家族は、REAL ID ではなく、標準の免許や州IDになることがあります。資格は窓口と、その時点の公式案内で確認してください。SSN の取り方は「[社会保障番号（SSN）](/topics/social-security-number/)」を見てください。

一時的な滞在資格の人の REAL ID は、<strong>合法的な滞在の期限と同じ日に切れます</strong>（州務省）。期限を延ばしたら、延長を示す書類を出して、新しいカードを申請します。カードに Limited Term と書かれるのは、上記の州法のとおりです。

## 必要な書類

イリノイ州の案内では、次の4種類を揃えます。すべて有効期限内の<strong>原本</strong>です。コピーは使えません。携帯電話の画面も、そのままでは出せません。住所の証明は、印刷した電子明細でもよい、とされています。口座番号が見えることが必要です。

1. <strong>氏名、生年月日、市民権または合法的な滞在</strong>（1点）：パスポート、出生証明書、永住者カード、雇用許可証（EAD）など。就労ビザなどで来る人の例は、<strong>米国のビザが付いた外国のパスポートと、直近の入国を示す承認済みの I-94</strong> です（州の行政規則、州務省のチェックリスト）。I-94 は、税関・国境警備局（CBP）のサイトから印刷できます。いまの氏名がパスポートと違うときは、婚姻証明書など、名前をつなぐ書類が必要です。パスポートがいまの氏名なら、そのつなぎは不要、と州務省は案内しています。
2. <strong>SSN の全部が載った書類</strong>（1点）：社会保障カード、番号の全部が載った W-2 や 1099、氏名と番号の全部が載った給与明細など。すでに有効なイリノイ州の免許や州IDがあり、以前に SSN を出していれば、この1点は不要なことがある、とされています。
3. <strong>イリノイ州の住所の証明</strong>（2点）：姓名と、申請する住所が一致していること。例は、90日以内の公共料金の明細（電気、水道、ごみ、電話、ケーブル、ガス）、賃貸契約や賃貸借、90日以内の銀行明細、給与明細、90日以内のクレジットカード明細、家や借り家の保険証券、州・郡・村・連邦からの公式郵便などです（州務省のチェックリスト）。使える書類の一覧は、公式のチェックリストで確認してください。筆者の場合、ペーパーレスで届く銀行や公共料金の明細をPDFで印刷したものが、住所の証明として通りました。携帯電話の画面ではなく、州務省の公式チェックリストで対象かを確かめたうえで、印刷した紙を持っていきます。
4. <strong>署名の確認</strong>（1点）：いま持っている星のないイリノイ州の免許、クレジットカードやデビットカード、パスポート、キャンセル済みの小切手など。

チェックリストは案内であり、提示したから必ず発行されるとは限らない、と州務省は注意しています。不明な点は、REAL ID の案内電話 833-503-4074 や、州務省の公式サイトで確認してください。

## 予約、手数料、紙の仮カード

申請は、イリノイ州の Driver Services の施設へ本人が出向きます。郊外の施設の多くは予約が必要なことがあるので、公式の予約ページで確認してください。シカゴ市内には、予約不要の REAL ID 窓口（Supercenter、191 N. Clark St.）が、州務省の案内では 2026年末まで開いている、とされています。時間や期間は変わるので、行く前に公式サイトで確かめてください。

REAL ID の手数料は、標準の免許や州IDと同じです（州務省）。公式の手数料一覧では、普通の運転免許証（21歳から68歳）は <strong>30ドル</strong>、5年の州ID（18歳から64歳）は <strong>20ドル</strong> です。年齢などで違うことがあるので、行く前に一覧を見てください。視力検査や、筆記・実技が必要になることもある、とチェックリストにあります。試験の有無は、免許の記事と窓口で確認してください。

申請が終わると、その場で紙の仮の免許または州IDが渡され、本カードは郵便で、15日以内（本カードの案内では15営業日以内とも書かれています）に届く、とされています。州務省は、予定があるフライトの少なくとも30日前には申請するよう勧めています。紙の仮カードは、TSA の認める REAL ID ではありません。届かないときは、公式サイトで郵送状況を確認できます。

## まとめ

- REAL ID の施行は 2025年5月7日。国内線の検査や、多くの連邦施設では、星のある州の免許・IDか、パスポートなど別の認められる身分証明が必要
- 日本のパスポートは、TSA が認めている身分証明の一つ。国内線では、REAL ID とパスポートの両方は不要。国外へはパスポートが必要
- 運転だけなら、星のない標準の免許で足りる
- イリノイ州の REAL ID は、カード右上の金色の星で見分けられる。一時滞在の人のカードは Limited Term と書かれ、滞在資格の期限で切れる
- 合法的な滞在と SSN があれば、就労ビザなどでも申請できる。書類は、身分と滞在、SSN、住所2点、署名。原本を持っていく
- 手数料は標準の免許・州IDと同じ（例：21〜68歳の免許は30ドル）。多くの施設は予約制。本カードは郵送で、紙の仮カードは空港では使えない
- 星のある免許と星のある州IDは、一人1枚だけ
