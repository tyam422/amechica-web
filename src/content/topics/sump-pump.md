サンプポンプ（sump pump）は、地下室に入る地下水を外へ出す装置です。日本の家には地下室自体が少ないため、電源が落ちたときや故障時に浸水する、という発想がまずありません。シカゴ郊外の一戸建てでは、地下室の隅に穴（sump pit）があり、水が溜まるとポンプが外へ排出する、という仕組みがよくあります。すべての家にあるわけではありません。賃貸か購入かの話は「[借りるか買うか](/topics/renting-vs-buying/)」、停電は「[水道・電気・ガスの開通](/topics/setting-up-utilities/)」、下水管の逆流は「[下水管（粘土管）と木の根](/topics/sewer-pipes-and-tree-roots/)」、緊急時は「[緊急通報（911）](/topics/calling-911/)」を見てください。発電機を地下室で使うと、一酸化炭素の危険があります。CDC と Ready.gov の案内を先に読んでください。

## 何のための装置か

地面の水や、基礎のまわりから入る水（footing drain など）を、地下室の床より下の穴に集め、ポンプで屋外へ出します。動かないと、地下室が浸水し、荷物や設備が傷み、カビの原因になることがあります。FEMA の Cook County 向け都市型浸水の案内（2024 年、2025 年 5 月改訂）でも、地下室の浸水経路の一つとして、サンプポンプの有無、電池の予備、警報、年 1 回の維持が確認項目に挙がっています。ポンプは大量の水や、停電時には対応できず、予備の電源や発電機が必要になる、とも説明されています。下水管から床の排水口へ逆流する水とは、原因が違うことが多いです。後者は下水管の記事を見てください。

イリノイ州の配管規則では、地盤の排水や基礎の排水を受ける槽と、汚水をくみ上げる槽を分け、汚水用の槽に地盤の水を入れてはならない、地盤用の槽に汚水を入れてはならない、とされています（77 Ill. Adm. Code 890.1360）。家にある装置がどちらの用途か、入居時に確認してください。

## 点検と試し運転

FEMA のサンプポンプ維持の案内では、少なくとも年 1 回、状態を見るよう示されています。電源を切ってポンプを穴から出し、ごみを除き、吸込口の網を掃除し、逆止弁（check valve）を点検してから戻し、電源を入れて、穴にバケツの水を注いで実際に起動する、という手順が説明されています。掃除のときは、ゴーグルと手袋を使う案内があります。電源を切る前に、コンセントや周囲が濡れていないかを見てください。立っている水の中に入って電源を切らなければならないときは、CDC は電気技師に依頼するよう案内しています。

試しに水を入れるときは、排出先が屋外で開いているか、冬なら管が凍って塞がっていないかも、外から確認します。ポンプが起動しない、異音がする、水がすぐ戻ってくる（逆止弁の不具合のことがあります）、排出が基礎の近くに溜まる、というときは、取扱説明と修理の業者を当たってください。FEMA の案内では、使用年数や、雨のときに動かない、頻繁に入り切りする、家のまわりに深い水たまりができる、といったときに交換を検討する項目も示されています。年数の目安は公式ページで確認し、この記事では断定しません。メーカーの説明が優先します。

## 停電の予備と、発電機

大雨と停電が重なると、主電源のポンプは止まります。Ready.gov と FEMA の都市型浸水案内は、電池などの予備電源を検討するよう説明しています。予備がある家では、充電の表示、電池の状態、予備側が実際に起動するかは、メーカーの手順で確認してください。イリノイ州の配管規則は、水道の圧力で動く予備ポンプ（water-powered sump pump）を、緊急の予備としてだけ使う、電池式の警報を付ける、効率や逆止弁の条件を満たす、といった定めがあります（77 Ill. Adm. Code 890.200(k)）。付いている装置の種類は、現物と説明書、必要なら配管の専門家で確認してください。この記事は、特定の予備の方式を勧めるものではありません。

予備のためにガソリン発電機を使うときは、CDC と Ready.gov は、屋内、地下室、ガレージ、窓や換気口から 20 フィート（約 6 メートル）未満では使わない、と案内しています。一酸化炭素は、窓を開けていても溜まります。不調なら外に出て、緊急なら 911 です。発電機を家の配線に、認可された切替装置なしでつなぐことは、電気の規則に反し、復旧作業の人にも危険になる、と CDC は注意しています。詳細は「[暖房とエアコン](/topics/heating-and-air-conditioning/)」の一酸化炭素の考え方も参考になります。

## 排出先のルール

イリノイ州の配管規則は、地下水、屋根の排水、基礎の排水管からの排出、その他の雨水を、汚水用の排水設備（sanitary drainage system）へ出してはならない、としています（77 Ill. Adm. Code 890.200(b)）。村の条例が、さらに排出の位置や、隣地への迷惑を定めていることがあります。

公式の例として、Village of Arlington Heights の条例は、地下水や雨水を受けるサンプポンプは、雨水用または合流式の下水管、または排水溝へ出し、汚水管へは出さない、排出管は原則として建物から 10 フィートを超えて伸ばさない（技術担当の書面承認があるときを除く）、隣地に迷惑にならない向きにする、と定めています（Municipal Code Chapter 22）。村の技術案内では、汚水管への排出は不可、凍結時にポンプが空回りしないよう空気の隙間（air gap）を設ける、といった説明もあります。ここに挙げた村は、公式の条文がある例であり、特定の村を勧めるものではありません。住む村の建築・公共事業の窓口と、現行の条例で確認してください。排出を道路や歩道へ出すと、冬に凍って危険になる、と案内する村もあります。

屋根の雨樋（downspout）の水を、基礎のそばや、サンプの穴の近くに落とすと、ポンプの負担が増えることがあります。向きは、村の雨樋のルールと、土地の傾斜で確認してください。

## 浸水したとき、保険、賃貸

床に水がある、コンセントが濡れている、水が深いときは、無理にポンプや配線に触らないでください。Ready.gov は、濡れた電気機器に、水の中から触れない、安全な場所から電源を切れるときだけ切る、と案内しています。CDC も、主電源を乾いた場所から切れるなら切る、水の中を歩いてスイッチに行く必要があるなら電気技師に頼む、としています。下水を含む水のことがあるので、長靴や保護具の案内もあります。安全が確認できたあとの乾燥とカビは、CDC の浸水後の案内と、カビの清掃案内を見てください。CDC は、できるだけ 24 時間から 48 時間以内に乾かす、子どもを清掃に参加させない、カビが見えるときはファンで拡散しない、漂白剤とアンモニアを混ぜない、と説明しています。この記事は、個別の清掃手順の代わりではありません。

通常の住宅保険は、洪水（flood）の損害を対象にしないことが多い、と FEMA は案内しています。洪水の保険は別の証券（National Flood Insurance Program など）であることが普通です。地下室の仕上げや、サンプの溢れが対象になるかは、証券と NFIP の公式説明で限られていることがあります。この記事では、対象になると判定しません。保険会社と、FloodSmart.gov の案内で確認してください。写真を残す、家主や管理会社にすぐ連絡する、は、賃貸でも購入でも有用です。

賃貸では、設備の維持は所有者の責任とされることが多い一方、異常の連絡は借り手の側に求められることがあります（州の配管規則は、設備の維持を所有者の責任とする条文があります）。契約書を優先し、動かない、水が増えている、異音がする、といったことは、早く書面でも伝えてください。購入の点検では、ポンプ、予備電源、警報、過去の浸水の跡、排出先を見てもらう話が出ることがあります。

## まとめ

- サンプポンプは、地下室に入る地下水を外へ出す装置。無い家もある。汚水をくみ上げる装置とは別、と州の配管規則は分けている
- FEMA は、年 1 回の点検と、穴に水を入れて試す案内をしている。停電用の予備も、Ready.gov と FEMA の都市型浸水案内で検討するよう示されている
- イリノイ州の配管規則は、地下水や基礎の排水を汚水管へ出してはならない、としている（77 Ill. Adm. Code 890.200(b)）。排出の位置は村の条例でも確認する
- 電源を切ったままにしない。水と電気が同時にあるときは、無理に触らない。発電機は地下室や屋内で使わない（CDC、Ready.gov）
- 通常の住宅保険は洪水を対象にしないことが多い。地下室や溢れの扱いを、証券と公式の洪水保険の案内で確認する
- 賃貸なら、異常は家主に早く伝える。維持の責任は契約と州の規則で確認する
