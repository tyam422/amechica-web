給与明細（pay stub）には、税、社会保障、医療保険、401(k)などの控除が並びます。年末の W-2 は確定申告の基本資料です。日本の給与明細と項目が違うため、最初に読み方を知っておくと安心です。申告は「[確定申告（tax filing）](/topics/filing-taxes/)」、退職貯蓄は「[401(k)の基本](/topics/401k-basics/)」、医療保険の天引きは「[医療保険の用語（deductible / copay / in-network）](/topics/health-insurance-terms/)」、番号は「[社会保障番号（SSN）](/topics/social-security-number/)」を見てください。明細の用語は、勤務先や給与計算の会社で表記が違います。分からない行は、人事または給与の担当に、その行の意味を聞いてください。

<div class="checklist">
<p class="checklist__title">最初の給与のあとにやること</p>
<ul>
<li>総支給（gross）、控除の内訳、差引支給（net / take-home）を、明細で照合する</li>
<li>連邦所得税、州所得税、Social Security、Medicare の天引きが、予想と大きく違わないか見る</li>
<li>医療保険料、401(k)、FSA / HSA など、税引き前の控除の行を確認する</li>
<li>Form W-4（源泉の申告書）の内容が、いまの家族の状況と合っているか、人事に確認する</li>
<li>暦年が終わったら、Form W-2 の到着時期と、明細の年間累計（YTD）との違いがないかを見る</li>
</ul>
</div>

## 明細の主な項目

gross pay は、その支給期間の総支給です。そこから、税、保険料、退職拠出などが引かれ、残った額が net pay（実際に口座へ振り込まれる額）です。日本の「額面」と「手取り」に近い対比ですが、控除の種類と、税引き前か税引き後かが、明細の行で分かれます。年始からの累計は、YTD（year-to-date）と書かれることが多いです。

連邦の所得税（Federal income tax）は、Form W-4 の内容と、その期の対象所得などを基に、勤務先が源泉徴収します。多く取りすぎていれば還付、少なければ申告時に追加納付、となり得ます。W-4 の書き方は、IRS の説明を見て、必要なら専門家に確認してください。この記事は、記入例を勧めるものではありません。イリノイ州の所得税も、州の源泉の案内に沿って天引きされることがあります。IDOR の案内では、個人の所得税は定率（flat rate）で、近年は 4.95% と説明されています。率は改正され得るので、その年の公式案内で確認してください。地方の給与税が別にあるかどうかも、住所と勤務地の公式案内で見てください。

Social Security（OASDI）と Medicare は、連邦の給与税（FICA）です。従業員の率は、法律で Social Security が 6.2%、Medicare が 1.45%、とする案内があります（SSA、IRS）。Social Security には、その年の課税賃金の上限（wage base）があります。額は年によって変わるので、SSA または IRS のその年の発表を見てください。この記事では、当年の上限額を書きません。一定以上の賃金には、追加の Medicare 税がかかるルールもあります。対象かどうかは、IRS の案内で確認してください。雇用主も、別途、対応する税を負担します。明細に出るのは、主に従業員負担分です。

## 税引き前の控除と、W-2

医療保険の保険料、Flexible Spending Account、条件を満たす 401(k) の traditional 拠出などは、税引き前（pre-tax）として、源泉の対象賃金から先に除かれることがあります。Roth の 401(k) は、税引き後の扱いになることがあります。どちらに記録されているかは、明細の行と、プランの説明を見てください。控除の結果、連邦の対象賃金と、Social Security の対象賃金が、同じ数字にならないことがあります。誤りかどうかを自分で決めず、給与の担当に質問してください。

Form W-2 は、暦年の給与と、源泉した税などを、雇用主が従業員と、税務当局に報告する用紙です。IRS の案内では、従業員への交付は、原則として翌年の 1 月 31 日まで、とされています。届いたら、Box の説明（連邦の賃金、源泉税、Social Security の賃金と税、州の情報など）を、明細の YTD と照合してください。数字が合わない、届かない、紛失したときは、まず勤務先に再発行を依頼し、必要なら IRS の案内を見てください。確定申告では、W-2 の内容を申告書に転記します。電子交付に同意しているときは、ポータルの案内を、年末に確認してください。

引っ越しや、年度の途中で勤務先が変わったときは、W-2 が複数になることがあります。古い住所に届かないよう、人事と、郵便の転送（「[郵便と住所の届け出（USPS）](/topics/mail-and-address-change/)」）を更新してください。

## まとめ

- 明細は、総支給から税と控除を引いて、差引支給になる。YTD は年初からの累計
- 連邦と州の所得税の源泉に加え、Social Security 6.2% と Medicare 1.45% の従業員負担がある（SSA / IRS）。賃金の上限はその年の公式発表で確認する
- 医療保険料や traditional の 401(k) は、税引き前になることがある。Roth は扱いが違うことがある
- W-2 は、原則として翌年 1 月 31 日までに交付。申告の基本資料として、明細の累計と照合する
